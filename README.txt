SATVIK ROOTS — OPENCODE STARTER PACKAGE

Contents:
- Satvik Roots breif and prompts.pdf: original 21-page brief with embedded visual references.
- SATVIK_ROOTS_OPENCODE_MASTER_PROMPT.md: detailed OpenCode instructions.

How to use:
1. Extract/copy both files into the root of the Satvik Roots website repository.
2. Open that repository in OpenCode.
3. Paste the Markdown prompt into OpenCode.
4. The prompt tells OpenCode to read the PDF and inspect its images before coding.
